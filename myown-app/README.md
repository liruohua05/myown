# My Own App Prototype

This is a static prototype for a personal weekly founder operating app.

## Files

- `prototype.html` - current mobile app prototype with weekly navigation.
- `prototype.css` - prototype styling.
- `prototype.js` - prototype interactions and local save behavior.
- `index.html` - earlier web dashboard version.
- `styles.css` and `app.js` - earlier web dashboard styling and behavior.
- `figma-app-prototype-brief.md` - Figma design brief.

## Preview

Open `prototype.html` in a browser.

## Main Structure

- Left rail generates recent week tabs automatically.
- Clicking a week opens the current weekly overview.
- Finance and startup management appear as sub-tabs under the active week.
- Startup progress and todo text are saved locally in the browser.
